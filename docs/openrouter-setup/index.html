Setup guide

Set up Deep check with OpenRouter

Deep check lets an AI model read the text inside your ad creatives and spot visual risks that the quick local checks can't see. It needs an API key from OpenRouter. This takes about two minutes, and you only do it once.

Optional. AdCheck's copy checks, hover explanations and quick creative checks work without any key. You only need this for Deep check.

Create your key

  1. Sign in to OpenRouterGo to openrouter.ai and sign in with Google, GitHub or email.
  2. Open the Keys pageVisit openrouter.ai/settings/keys and click Create Key.
  3. Name it and cap itCall it AdCheck. If you see a credit limit field, set a small cap. It's a safety net, not a requirement.
  4. Copy the keyIt starts with sk-or- and is shown only once. Copy it before you close the dialog. Don't share it or paste it into chats, screenshots or public repos.

Add it to AdCheck

  1. Open the side panelClick the AdCheck icon, or press Alt+Shift+A.
  2. Open Deep check settingsScroll to the bottom of the panel and expand Deep check settings.
  3. Choose a modelLeave it on Gemma 4 31B (OpenRouter). If it's busy, AdCheck automatically tries a backup model.
  4. Paste and savePaste your key into the field and click Save key. You should see "Key saved". The key is stored only in your browser.

Run your first Deep check

  1. Open your ad in Meta Ads ManagerThe creatives in the preview appear in the panel's Creatives section.
  2. Click Deep check on a creativeAfter a few seconds you'll see a one-line summary, any visual risks with fixes, and the text read from the image, which is also checked against the same rules as your copy.

If something goes wrong

What you seeWhat it means and what to do
Key rejected (401)The key is wrong or was deleted. Create a new one and save it again in the panel.
Credits needed (402)The model you picked needs a balance. Switch back to the default model, or add credits on OpenRouter and keep a spend cap on the key.
"Rate-limited upstream" or "Provider returned error"The model's provider is busy. AdCheck retries on backup models automatically. If all fail, wait a minute and click Re-run deep check.
Answer was cut offThe model ran out of room. AdCheck still shows the text it managed to read. Run it again for the full result.
"Couldn't read this image's pixels"Chrome couldn't load that image. Use another creative, or open the ad preview again and fetch.

Privacy, cost and safety

  • What is sent. Only when you click Deep check, one image from your ad goes to OpenRouter and the model provider behind it. Your ad copy is never sent.
  • Logging. Depending on the model, the provider may log prompts and images. Avoid sending confidential client creatives.
  • Cost. The models AdCheck uses by default don't need a balance. If you choose a paid model later, set a spend cap on the key.
  • Revoking. You can delete the key any time at openrouter.ai/settings/keys, and remove it from AdCheck with Remove key.
  • Prefer Claude? Choose Claude (Anthropic API) in the model list and paste an Anthropic key from console.anthropic.com instead. It needs paid credit.
